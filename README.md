# TuckBook 💰
### Credit & Debt Tracker for Informal Businesses

> Track credit. Get paid. Grow your business.

A lean mobile app built for tuck shop owners, spaza shops, and market vendors in Sub-Saharan Africa to track customer debt and send one-tap WhatsApp payment reminders.

## Quick Start

```bash
npm install
npx expo start --android    # Test with Expo Go
eas build --platform android --profile apk  # Build APK
```

## Features (MVP)
- Record customer credit and payments in seconds
- See total outstanding balance at a glance
- Send pre-written WhatsApp payment reminders with 1 tap
- Works 100% offline (SQLite local database)
- Search and sort customers by balance
